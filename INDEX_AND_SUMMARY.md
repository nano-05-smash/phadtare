## 🚀 Getting Started (5 Minutes)

### Quick Start Steps
```bash
# 1. Create project
npx create-next-app@latest phadtare-platform --typescript --tailwind

# 2. Copy configuration files
cp next.config.ts package.json tsconfig.json tailwind.config.ts ./

# 3. Setup environment
cp .env.example .env.local
# Edit .env.local with your credentials

# 4. Install dependencies
npm install

# 5. Run development server
npm run dev
# Open http://localhost:3000
```
